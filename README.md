# 🚀 Synapse AI

Synapse AI is a voice-controlled intelligent assistant built using Python.  
It listens to user commands, processes intent, and executes real-world system actions such as opening websites, playing music, and performing automation tasks.

This project represents the foundation of a larger vision: building scalable AI-driven automation systems.

---

## 🧠 Features

- 🎙 Voice-based command execution  
- 🌐 Open websites via voice  
- 🎵 Play music using a custom music library  
- ⚡ Fast local execution  
- 🧩 Modular architecture for future expansion  

---

## 🛠 Tech Stack

### AI Assistant
- Python  
- pyttsx3 (Text-to-Speech)  
- SpeechRecognition  
- Automation modul
